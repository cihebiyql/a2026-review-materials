## 一、叙事主线（一句话）

**"评估器对齐的机理建模 → 结构感知构造 + 学习式优先级指派（离线训练/在线秒级求解两段式）→ 预算内精修"三层递进，在官方确定性评估器下逐问给出 1–5 核加速比曲线与逐用例交付表。**

关键叙事决策（已定）：
1. **两段式架构是全文骨架**：离线阶段（REINFORCE 训练每例的优先级参数 logits + 超参校准）与在线阶段（加载参数 → 采样解码 → 预算内精修，单用例 ≤8 分钟）。论文全部正文数字由在线求解器产出；离线充分搜索的池数字仅作"校准上界"参照（gap 分析表）。这一叙事天然满足题面"5–10 分钟内/禁止暴力迭代搜索"脚注。
2. **SA/网格扫描从正文方法退场**：改写成"离线校准与消融"素材；正文方法主角 = 构造解码器 + 学习式指派。
3. **机理章是差异化底牌**：三地板下界模型（每核串行/带宽/关键路 max）、签名类定理与辫状图钳形证书（理论线已有成品 tex）、"加速比>核数"的解释（单核基准被 spill 拖慢）。

## 二、章节结构与内容映射

### 滴摘要（六要素）
问题重述两句 | 模型：三层决策（cut/assign/order）+ 三地板 makespan 下界 | 方法：构造解码 + one-shot 优先级采样指派（引 ICLR23）+ 预算内精修 | 结果：P1/P2/P3 的 N=1..5 平均加速比（正文曲线峰值数） | 有效性：官方评估器 bit-exact 对拍 + 消融（学习先验贡献最大等） | 创新点：①评估器对齐的领域化解码器 ②段单元合法性构造引理 ③两段式合规架构。

### 一、问题分析与机理建模
- 1.1 三层决策形式化（cut/assign/order，约束与合法性条件）
- 1.2 评估器机理（step1/2/3 + 事件仿真；三地板下界公式；跨核 500/1000cyc、同核免费、L2 FIFO 侧带）
- 1.3 数据体检结论（并行上限中位 28 倍、双管异质、共享张量 vs L2 容量）→ 引出"瓶颈全在可控决策空间"

### 二、求解方法（正文算法 = 在线求解器）
- 2.1 结构感知构造：链分解（弱连通分量）与拓扑段单元（辫状图自适应，含**段批合法性引理**：批合并当且仅当全局排名相邻且同核 ⇔ 商图无环——附构造证明，6 行）
- 2.2 学习式优先级指派（方法核心，引 [n] Jeon et al. ICLR23）：
  - 每单元 logit θᵤ；采样 = θ + i.i.d. Gumbel → argsort（Gumbel-Top-k，无放回采样的可并行形式）
  - 领域化解码器：贪心指派代价 = max(W_M(c)+w_M(u), W_V(c)+w_V(u)) + λ₁·跨核共享张量字节 − λ₂·P3 摊开奖励
  - 重标：batch×level 网格（B×L）把指派转成子图方案
  - 训练（离线）：REINFORCE，梯度 = E[∇log π(序)·C̄]，批内代价标准化 + logit 范数正则（c=0.001）
- 2.3 在线求解流程（正文伪代码 = solve_compliant.py）：
  ```
  输入 case → 构造单元 → 加载离线参数(θ, B*) → 贪心+S(k) 采样解码
  → 预算内爬山精修(单元搬核/序换位/B 邻域) → 输出方案    [≤8 分钟]
  ```
- 2.4 合规性说明：题面脚注口径的逐条对照表（时间预算、非暴力搜索、复现附件）
