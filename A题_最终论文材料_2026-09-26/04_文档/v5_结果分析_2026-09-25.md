# v5 学习式核指派 · 战役结果分析（2026-09-25）

> 方法来源：ICLR 2023《Neural DAG Scheduling via One-Shot Priority Sampling》
> (Jeon et al., Qualcomm AI Research, OpenReview: WL8FlAugqQ) 的 A题移植。
> 全部改进均经官方评估器 bit-exact 终验。

## 一、方法概览

把论文的 "one-shot 优先级采样 + 确定性解码器 + REINFORCE" 配方搬到 A题
（通用神经网络处理器多核调度）的**核指派层**：

```
链/段 logit ──Gumbel-Top-k──> 单元全局序
   ──> 贪心核指派解码器(双管线均衡+通信项+P3摊开奖励) ──> op→core
   ──> mechA 重标(冠军 B×L, 段模式用排名相邻同核合法批) ──> 子图方案
   ──> FastEval bit-exact 评估 ──> REINFORCE(批内代价标准化 Eq.13
       + logit 范数正则 c=0.001) ──> Adam 更新 logit
```

与论文的对应关系及两点本土化改造：

| 论文组件 | v5 对应 | 备注 |
|---|---|---|
| 节点优先级 logit | 链(弱连通分量)/拓扑段 logit | 段单元为本工作新增(辫状图链退化) |
| Gumbel-Top-k 采样 | 同(全局 argsort) | 原样移植 |
| list scheduling 解码 | 指派解码器 + mechA 重标 | 解码器内嵌题目领域知识 |
| REINFORCE + Eq.13 | 同 | 原样移植 |
| logit 范数正则 | 同(c=0.001) | 原样移植 |
| Topoformer GNN | **不用** | 100 测例固定已知,逐例训练合法且更便宜 |
| S(k) 采样取最优 | best-so-far + greedy | 原样移植 |

## 二、试点结果（P1 门, 5 例, 50轮×128采样/例）

| 案例 | 单元模式 | 冠军 sp | v5 后 | Δsp | 官方终验 |
|---|---|---|---|---|---|
| case_095 | 链(462) | 7.7615 | **7.9040** | **+0.1424** | ✓ bit-exact |
| case_084 | 链(1077) | 8.7942 | **8.8344** | **+0.0402** | ✓ bit-exact |
| case_029 | 段(21→96) | 4.5715 | — | 0 | 跑满50轮 |
| case_064 | 段(1→91) | 1.3043 | — | 0 | 跑满50轮 |
| case_045 | 段+隔离 | 4.8888 | — | 0 | 跑满50轮(平台补丁验证例) |

**核心量化结论**：
1. 指派层学习有效：case_095 收益 −4841 cycles，是重标层(v4 实验,同例)
   收益 −124 cycles 的 **39 倍**——"剩余分数在核分配层"的判断被定量证实。
2. 方法边界清晰：**胜率与链富集度完全相关**——链模式 2/2 全胜，
   段模式 0/5(辫状图的瓶颈是接力结构,LPT 均衡先验捕捉不到)。
3. 全库适用面：n_chains≥100 的链富集例共 **27/100**。

## 四、工程发现（三条,均已实证）

1. **段模式商图成环引理**：辫状图(单弱连通分量)在链参数化下退化,须切
   拓扑段;但段间有依赖,任意合批会在商图织环(跨核段排名区间交错)。
   修复 = 批只允许**全局排名相邻且同核**的段合并(`relabel_perm_seg`)。
   B=4(单段批)合法/B≥16 成环的实测 + 24/24 合法性对拍,构造正确。
2. **FastEval 多实例堆损坏**：同一进程评估多案例/多形状方案会触发
   numba 层堆损坏(glibc "corrupted size vs. prev_size"),跨 numba
   0.60(node23)/0.65(ksai) 复现,与 014/040 已知崩图同类。
   规避 = **单案例单进程**纪律 + **--isolated 隔离评估**(每方案一次
   子进程,崩溃计 None,主进程免疫)。case_045 在隔离模式完整跑完验证。
3. SA 战役从未踩坑的原因：逐点邻域方案形状相近 + 单案例进程,与本
   发现互洽。

## 五、复现指南

环境：Python 3.11+（numpy/numba），官方附件（code/ + data/ + config.txt）。

```bash
# 0) 目录布局: 任意工作区/
#    v5包/src + deps + 官方附件(att/code, att/data) + 单核基准(results/singlecore)
#    环境变量: A2026_ROOT=工作区根  A2026_ATT=附件根  A2026_SC=单核基准目录
#             A2026_ROUT=结果输出目录

# 1) 管线自测(必须 bit-exact: best == mk0)
python reinforce_assign.py 3 case_064 --iters 1 --N 8 --workers 2 --stub

# 2) 单案例训练(正常模式)
python reinforce_assign.py 3 case_095 --iters 50 --N 128 --workers 16

# 3) 崩溃类图(045/016/062/014/040族)用隔离模式
python reinforce_assign.py 3 case_045 --iters 50 --N 128 --workers 16 --isolated

# 4) 全库扫(崩溃自动降级隔离)
bash v5_sweep_launch.sh
```

结果判读：jsonl 中 `official_match: true` 且 `sp_best > sp0` 的行 =
官方验证过的真改进；对应方案 json 自动落盘于 A2026_ROUT。
