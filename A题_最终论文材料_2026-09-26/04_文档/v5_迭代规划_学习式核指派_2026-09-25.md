## 0. 一句话方案

把论文的"one-shot 优先级采样 + 确定性解码器 + REINFORCE"从重标层上移到
**指派层**：学每条链的优先级 logit → Gumbel-Top-k 采样链序 → **双资源均衡指派
解码器**（题目领域知识内嵌）→ mechA 重标（冠军 B×L 配置）→ FastEval/GPU 真值
→ REINFORCE（批内代价标准化 + logit 范数正则）。

## 1. 为什么是指派层（证据链，全部已实测）

| 证据 | 来源 | 含义 |
|---|---|---|
| 重标空间强例饱和 | 09-25 REINFORCE 实验：084/095/008 共 50 轮仅 −1/−124/0 cycles | 切图+排序维度已榨干 |
| 中段例对重标零敏感 | 016/002：128×N 采样 makespan 方差为 0 | **不改 op→core 分配，中段例一分都动不了** |
| 中段 6 例天花板 <5.05 | ceiling_all100.csv | 结构上限存在，但当前 3.4~4.5 距上限还有余量 |
| SA 战役仍在指派邻域得分 | 09-25 战报：move/swap/segmove/focus_move 持续收割 | 指派层是活水源，但 SA 均匀邻域效率低 |
| P2/P3 缺口 80/70 点 | 最新进展文档 | 目标主战场 |

**v5 的赌注**：SA 用手工邻域 + 逐点真值探索指派空间；v5 用学习到的采样分布
整体搜索指派空间（长程结构 SA 要链式多步才能到达），并顺带获得合规的快速求解器。

## 2. v5 架构

```
输入: case 图 G, 冠军方案(热启动), 链分解 comp_of
  │
  ▼ logits(链) ∈ R^n  ←─ REINFORCE 更新(Adam, lr=0.05, 代价标准化Eq.13, logit范数正则c=0.001)
  │
  ▼ + i.i.d. Gumbel → argsort = 链全局序（Gumbel-Top-k, 论文§2.3）
  │
  ▼ 指派解码器（确定性, 领域知识内嵌）:
  │   按链序逐条指派到核, 代价 = max(ΔM负载, ΔV负载)   ← 双 Pipe 均衡(题面隐含偏好)
  │         + 切边流量 Σs(t)×异核消费数×w_traffic      ← 三地板模型的带宽项
  │         + 同核亲和(共享张量) / P3: L2 复用奖励      ← 场景B免费通信+题三命中率
  │   平手规则: 与前驱同核优先(省跨核延迟)
  │
  ▼ mechA 重标: 冠军 B×L 配置, 链序=指派序（复用已验证代码）
  │
  ▼ FastEval(CPU)/GPU批内核 真值 → makespan → best-so-far 追踪
```

关键设计决策：
- **Design A（优先级+解码器，论文原味）**而非 Design B（逐链 N 路 softmax 直采指派）：
  解码器内嵌均衡与通信约束，指派合法性/质量由构造保证；序列似然 REINFORCE
  的全部代码已在 reinforce_order.py 里跑通，复用率 ~70%。
- **logit 在链级**而非 op 级：n=10²~10³（084 为 1077），维度可控；mechA 已证链是
  正确的参数化粒度。
- **logits 初始化 = 冠军方案诱导序**：起点即现任最优，训练只负责往上推——
  与 09-25 实验同策略（该实验证明此初始化可精确复现冠军 mk）。
- **q1/q2/q3 同骨架换解码器代价项**：P1 加 Task 切换/跨核等待(100/1000cyc)，
  P2/P3 加 500cyc 跨核与同核免费语义；P3 加 L2 命中奖励。

## 4. 分阶段推进与门槛（沿用 证伪门槛 纪律）

**试点组（09-25 对账试错台账+理论证书后修正）**：
- 084/095：强例，测"能否再推"
- 064：**SA 邻域枯竭（45,031 候选 0 合法）但 CP 重切 -8.5%**——空间存在、
  现有搜索分布够不着，恰好是 v5 学习分布的目标症状
- 029/045：近期 GPU 战役指派邻域仍在收割的活水例（各 2 次改进）
- 062：P3 理论残余 gap 最大（0.345），理论线指定杠杆=共享张量消费方跨核
  摊开+FIFO 读序对齐——与 v5 解码器 P3 奖励项直接对应
- 016（**P3 专属钳形破缺探针,单列,不计入过门**）：{016,024,051} 在 P1/P2
  被钳形证书封死（引理8-10 任意方案成立）；但证书推导于 09-23,早于 09-25
  发现的 P3 L2 侧池（250B/cyc 绕开 DDR 池）——带宽钳刀刃在 P3 被削弱,
  016 若在 P3 被指派学习打开,即是证书假设被打破的证据,单独成文

**Phase P1 原型（~1 天）**：指派解码器 + Design A 训练闭环。
- **过门条件：≥3/5 例 Δsp≥+0.02 且官方 bit-exact 终验通过** → 进 Phase 2
- 不过门且 016/002 仍零方差 → 中段例判定为纯结构地板，转攻强例余量 + 收官
- 不过门但中段例动了 → 解码器有效但训练弱，升 N/轮数再试一次

**Phase P2 全库 q3/q2（1-2 天）**：100 例 × 训练循环上 ksai 容器内闭环
（rollout 批天然匹配 [N,1] GPU 批内核,战报"待做"项合并落地）。
- **过门条件：单问平均 +≥0.5 点（Δavg_sp≥0.005）** → 入冠军池产线
- 否则降级为"SA 提议分布"（用学到的 logits 引导 SA 邻域选择,不动主产线）

**Phase P3 q1 + 收官（1 天）**：P1 场景解码器语义（切换税/跨核等待）+ 全库；
三问冠军池合并 + 次指标（额外搬运量/命中率）顺带收割入池。

**Phase P4（暂缓,用户已指示）**：交付面重建（N=2-4 曲线降核适配、复现包升级
为"logits+采样"秒级求解器）。注：v5 若成功,复现包合规问题自动解决一大半——
离线训练 + 在线 S(k) 秒级出解,正对题面"5-10 分钟/禁止暴力迭代"口径。

  用例成立

**已识别并修正的两处撞线风险**：

   且"随机序 vs 学到的序"消融从可选项升级为硬门（解码器增益不显著即换
   Design B 或杀）

## 9. 本版不做（明确划出）

- N=2/3/4 降核曲线（交付面,暂缓）
- GA/束搜索混合（论文附录H证伪+自家064邻域枯竭,双重证据关闭）
- GNN 跨图泛化（题目不要求,纯负担）
- 重标层继续调参（09-25 实验证伪:饱和+零敏感）
