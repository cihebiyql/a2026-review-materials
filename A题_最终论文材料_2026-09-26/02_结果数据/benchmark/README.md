# benchmark/ 基准测试材料（十算法 × 三问 × 100 用例 × 题面全指标）

官方评估器（未改动）逐例评测。全部记录含 Makespan、加速比、额外搬运、spill、
Cache 命中率（q3）、核内驻留峰值、求解时间、fallback 标记。

## 快速入口

**`汇总/BENCHMARK_SUMMARY.csv`** —— 一张表：每问每算法的均值加速比、样本数、
全指标均值、fallback 率、相对本文方法百分比（三问 × 十算法 + 本文共 33 行）。
