# 基准算法说明（A题 2026）

本目录收录论文基准对照所需的全部算法源码与数据出处。所有基准数字均由
**官方评估器**在题面 config 下产出，100 用例全覆盖，N∈{2,3,4,5}。

## 基准清单与数字出处

| 基准 | 源码位置 | 一句话算法 | 数字出处 |
|---|---|---|---|
| **B1 朴素 stub** | `baseline/v1_stub_baseline.py` | 随机/轮询切图分核，无优化 | 审题报告实测（部分用例, 0.73~1.5） |
| **B2 v2 结构感知构造+LS** | `v2_solver/`（pipeline/proxy/local_search） | 凸划分+两级代理+局部搜索，纯标准库 | **`02_结果数据/baseline/full_scan.jsonl`（400 行全量）** |
| **B3 v3 签名类装箱** | `v3_solver/`（p1_v3/p2_v3/common） | 弱连通签名类定理+波前+装箱 | v3 战役报告（代表例口径） |
| **B4 经典优先级启发式**（CP/SPT/MOPNR） | 评估器侧对照, 见 `baselines.py` 引用 | 关键路/最短工时/剩余作业数优先 | 论文基准区（与 B2 同框架评估） |
| 本文·最终方案轨 | `../repro/` | 两段式 v5（离线校准+精修） | final_results_table.csv |
| 本文·在线轨 | `../repro/` | v5 在线求解器（8 分钟） | final_results_table.csv |

## 基准均值速查（v2 全量实测, 100 例×各核数）

| 问题 | N2 | N3 | N4 | N5 |
|---|---|---|---|---|
| P1 | 1.6005 | 2.0746 | 2.3366 | **2.5827** |
| P2 | 1.6422 | 2.1573 | 2.5664 | **2.9418** |
| P3 | 1.6609 | 2.1879 | 2.6007 | **2.9830** |

**诚实说明**：v2 基线（构造+LS）在 N5 高于本文在线轨（2.58/2.94/2.98 vs
1.96/2.80/2.82）——在线轨的定位是"8 分钟端到端（含模型加载）的方法演示"，
其 LS 预算受时限约束；本文**最终方案轨**（3.6508/4.3132/4.3970）全面超越
全部基准（P1 +41% / P2 +47% / P3 +47% 相对 v2）。基准表建议按
`baseline_comparison.csv` 四行并排呈现，附本段说明。

## 复现

```bash
# v2 全量(产出 full_scan.jsonl 同构数据)
py -3.11 v2_solver/pipeline.py --cases data/ --N 5    # 单例; 批量见 deliver/run_all
# 逐行校验: full_scan.jsonl 的 makespan 为官方评估器输出, 可用 repro 内评估器复核
```

数据文件: `02_结果数据/baseline/full_scan.jsonl`（每行: case,N,K,p1/p2/p3 的
makespan+搬运量分解, solve_s）; 汇总: `baseline_comparison.csv`;
早期对照图: `v2_vs_baseline_fig.png`（v2 vs stub, 0923 时代产物, 供参考）。
