# 草稿历史留档（版本台账）

版本：v0.1
更新日期：2026-09-25
用途：保留论文草稿与工作区文件的历史版本，支持回溯、对比与回滚。机制为 git 本地提交 + 本台账人工可读索引（D019）。

## 机制

- 每个版本 = 一次本地 git 提交，提交信息格式：`A题写作区 V00N: 摘要`；查对应哈希用 `git log --oneline --grep "V00N"`。
- 留档触发时机：①用户确认一轮正文修改后；②重写/大改前（先留保险快照）；③每日收工时。
- 推送分仓（D032＋D040，2026-09-26 收紧）：团队总仓 shumo-toolkit 现阶段只取不改，任何 push 须先经用户逐次确认；个人镜像仓 paper-mirror-2026 的同步与推送**仅在用户明确指令后执行**（`jingsai_gpt_mirror/sync_to_github.sh`；本地镜像快照提交照常，随指令统一上传）。本地留档提交不受影响。仓库级 git 已配置作者身份与代理，无需附加参数。
- 版本号 V001 起顺序分配，不重用；仅笔记簿记、无正文变化的轮次不占版本号。
