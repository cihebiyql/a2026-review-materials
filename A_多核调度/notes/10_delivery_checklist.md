# 交付终检清单

版本：v0.1  
更新日期：2026-09-25

用途：定稿提交前的最终检查规程，合并官方《论文格式规范》（附件2，`../../../templates/官方模板_2026/附件2_论文格式规范.docx`）、官方 AI 规定（附件4，见 [09_ai_usage_log.md](09_ai_usage_log.md) 第1节）与团队技能的写作质量门（`skill/references/paper-quality-gates.md`、`skill/references/typesetting-notes.md`、`skill/assets/final-audit-checklist.md`）。

触发时机：全部章节在 [03_outline.md](03_outline.md) 记录“已审核”、结果冻结后，生成最终 PDF 时全量执行一次；其后仅修改则复检受影响项并在记录表注明范围。建模与实验正确性类终检（数据契约、泄漏、独立复核等）由算法侧负责，本清单覆盖写作、合规、排版与交付；涉及数值一致性的条目仍在此核对。

执行规则：**每项勾选须有证据指针**（文件位置、命令输出、记录编号），无证据或存在未解释冲突时不得勾选；未通过项写明处理动作与负责人，不得静默跳过。

## A. 证据与数字一致性

- [ ] 正文每个关键数值、区间、极值、排序和百分比可追溯到 [02_confirmed_results.md](02_confirmed_results.md) 的 RES 编号及适用范围；从源结果重算或经断言核对，不凭图形目测抄写。
- [ ] 主表和关键数字由脚本从机器可读结果（`results/results_summary.json`、`data/processed/`）程序化生成，`tables/` 以 `\input` 引用；无手抄数字表。
- [ ] **摘要逐数回查**（D044，三篇基准共同翻车点：2025A 摘要逐例峰值与正文表 0/6 对上、核心降幅复算不出；2021A 摘要 500 倍 vs 正文 600 倍）：摘要每个数字逐一在正文找到**同口径**出处并核对无打架；双数字口径（在线 harvest＋离线校准上界）两列各自对账、不得互相混写；峰值/均值/最佳/平均的口径限定词与正文逐字一致；摘要数字与 02 台账、图注三方一致（本项在 T023 之外，终检时人工逐数执行）。
- [ ] 每张入文图表在 `figs/figure_registry.csv` 中状态为“已核验/已入文”，数据工件与脚本列非空。
- [ ] 02 台账 §3.2 更新联动的受影响位置全部处置完毕，无遗留“待重审”的已引用结果。

## B. 摘要与篇幅

- [ ] 摘要包含六要素：建模思路、主要方法、模型、结果与结论、创新点、关键词（附件2）。
- [ ] 摘要一般不超过两页，无需译成英文（附件2）；一页内完成为原则（团队质量门）。
- [ ] 摘要不放图表、公式、引用和算法名清单，不出现正文没有的结果。
- [ ] 末尾 3–5 个能区分题目与方法的关键词。
- [ ] `preview`、`pool`、合成类指标未以“结果”句式进入摘要；如提及只用于“方法验证”句式并注明性质。
- [ ] 正文页数按口径统计：摘要页起至模型评价止，不含封面、目录、参考文献、附录和源码；默认目标 30–40 页，用户另有确认值时以确认值为准。
- [ ] 页数不足时已建缺口矩阵并完成第二轮证据型扩写（扩写项有证据来源：已有工件、可重算推导、新增实验、已核实引用或明确的限制分析）；两轮后仍未达标已请示用户（接受短稿或授权新增实验），无放大字号、拆表、贴码、重复背景等注水行为。

## C. 图表

- [ ] 每张图表先在正文引用、紧邻出现、随后有实质解释；不连续堆叠三张以上互不构成同一比较任务的图表。
- [ ] 同一结果的图和表不重复占正文，除非承担不同证据角色并说明。
- [ ] 图题、表题独立交代对象、样本/情景、单位、指标和统计口径；图题在 LaTeX `caption`，图内不带题。
- [ ] 成图矢量优先；位图不低于 300 dpi（`figs/README.md` 口径；团队出图模板默认 220 dpi，使用时覆盖）。按最终版面核对字号、中文字体与灰度可辨性。
- [ ] 示意图明确标注为示意，不与实验图混淆。
- [ ] 表格用三线表（顶线、表头线、底线，无竖线）；图表编号与交叉引用由 LaTeX 自动生成（`\label`/`\ref`），无手写编号；正文无硬编码节号（TODO 注释中的节号一并清除）。
- [ ] **图-正文交叉引用逐字复核**（D045，三篇基准共同翻车点：2023A 图 5.7 两处误引＋双联图"参数3/参数5"复制未改净、2021A 图 3.4/3.5 错引、2025A 图与正文算法名不一致——全出在后期组装章节）：每个"图 N/表 N/算法 N/参数名"在正文引用处与图表实际内容逐字核对；双联/多联图各子图的参数标注逐一核对；图表标题中的算法名/方法名与正文称呼一致（06 术语表口径）。
- [ ] **同题数据多图互斥分工兑现**（D045，防 2025A 图 6/图 7/表 4 三重呈现）：三件套（F19 均值趋势／F08 逐例离散／TBL-004 精确配对及 5/6 章对应物）的 caption 按 registry 拟稿的互斥口径落 tex，每题图表各管一个视角、图题内互相指认分工；F14(b) 单一口径（均值比或配对 S_Cache）定稿后不再混称。

## D. 语言门

- [ ] 已搜索并删除无比较、无证据修饰：“众所周知”“具有重要意义”“大大提高”“效果显著”“先进”“完美”及无依据的“最优”。
- [ ] 每个定量判断交代比较对象、样本/情景、指标和不确定性或边界。
- [ ] 术语、符号与 [06_glossary.md](06_glossary.md) 一致；周期/秒、字节/MB/MiB 换算按其中规则执行。
- [ ] 区分观察与解释、预测与因果（预测／观测方向／模型情景／干预效应不混用）；负结果与局限如实保留，不以总分口径掩盖。
- [ ] 无残留 Markdown 标记、口语占位、英文界面词、未定义缩写；润色未改变任何数值、方向、显著性和证据等级。
- [ ] **整章连读**（D048）：每章完成或并行稿合并后连读一次，逐项核对跨节重复（换说法复述同一机制/数据/交付——逐节合理、连读仍重复是高发形态）与论证重点（各节最重要的判断与证据是否被背景/过程淹没）；整合窗执行，首个对象＝已齐备的第一章（V010）。
- [ ] **去AI味全文扫描**（D049）：终稿轮对全部 sections 跑 skill deai-check（三档词表＋跨节结构模式——重复起手式、跨节排比、各节收尾句式同款）；A 档逐处改，B 档超限逐条仲裁（豁免口径见 skill 速查表），报告不重写、不改已仲裁表述。
- [ ] **再引用核对**（D048，00 §4.5 第 2 条）：抽查正文对图表的解释与跨节回指，逐处确认承担新作用（分析/论证/导航/自足注）、无换说法复述；正文逐项抄写表格数据属复述，指出数据支持的结论属新作用。
- [ ] **重点加粗复查**（D051）：运行 `scripts/check_bold_density.py`（统计 sections/appendix 的 \textbf/\bfseries 中文加粗密度，正文页数取 build PDF）；全篇密度落在 **0.5–1.5 处/页**；逐处核对落点限于口径清单（方法/模型/算法名首现、摘要与各问结果段关键结论＋核心数字、段首"问题X/阶段X"引导词、注意句），无整句连段加粗；数学变量与图表标题粗体不计入（调查依据：notes/20260926_国一正文加粗调查.md）。

## E. 参考文献与引用

- [ ] 不少于 15 篇真实且正文实际使用的文献，覆盖五类：领域背景、核心模型来源、评价/检验方法、数据/标准、软件/算法实现（覆盖表可用 `skill/assets/paper-quality-gate-template.md` C 节登记），无凑数。
- [ ] 正文引用处用方括号标示编号（如[1][3]）；文献按正文引用次序列出；引用书籍注明页码（附件2）。
- [ ] 三类表述式符合附件2原文：书籍（作者，书名，出版地：出版社，起止页码，出版年）、期刊（作者，论文名，杂志名，卷期号：起止页码，出版年）、网络（作者，资源标题，网址，访问时间）。
- [ ] 每条文献经过真实来源核对（作者、年份、题名、DOI/网址），无凭记忆补造；核对记录可追溯。
- [ ] `references.bib` 台账与正文手工 `thebibliography` 内容一致，且不会出现双重“参考文献”标题；AI 工具列出的条目为四段式。
